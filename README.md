>> My Storybook
My Storybook is a Japanese-inspired digital storytelling journal designed to preserve quiet moments, personal memories, travel experiences, and visual narratives. The website combines thoughtful writing with atmospheric photography to create a calm and immersive reading experience.
Inspired by Japanese ideas such as mono no aware, wabi-sabi, and yohaku, the design celebrates imperfection, meaningful empty space, and the beauty of passing moments.
Key Features
- Separate pages for stories, documentation, photography, and contact
- Japanese-inspired glassmorphism interface
- Responsive light and dark themes
- Smooth animations and ambient gradient backgrounds
- Interactive image gallery with a lightbox
- Responsive design for mobile, tablet, and desktop
- Accessibility and reduced-motion support
- Optimized WebP images and lazy loading
- Static generation for fast loading
- Automatic deployment through GitHub Actions and GitHub Pages
Technology
The project is built using Next.js, React, TypeScript, CSS, Turborepo, and Yarn Workspaces.


# Turborepo starter

This Turborepo starter is maintained by the Turborepo core team.

## Using this example

Run the following command:

```sh
npx create-turbo@latest
```

## What's inside?

This Turborepo includes the following packages/apps:

### Apps and Packages

- `docs`: a [Next.js](https://nextjs.org/) app
- `web`: another [Next.js](https://nextjs.org/) app
- `@repo/ui`: a stub React component library shared by both `web` and `docs` applications
- `@repo/eslint-config`: `eslint` configurations (includes `eslint-config-next` and `eslint-config-prettier`)
- `@repo/typescript-config`: `tsconfig.json`s used throughout the monorepo

Each package/app is 100% [TypeScript](https://www.typescriptlang.org/).

### Utilities

This Turborepo has some additional tools already setup for you:

- [TypeScript](https://www.typescriptlang.org/) for static type checking
- [ESLint](https://eslint.org/) for code linting
- [Prettier](https://prettier.io) for code formatting
